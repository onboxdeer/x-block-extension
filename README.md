# 🛡️ X / Twitter 评论一键拉黑助手（Chrome 扩展）

厌倦了评论区里的广告、辱骂、歧视和引战账号？这个小工具帮你在一篇推文的评论区里，**按自定义关键词批量筛选命中账号，一键全部拉黑**。

- ✅ 仅模拟点击、纯本地处理，**不上传任何数据**，无需登录第三方服务
- ✅ 覆盖 X（推特）桌面版网页，Chrome / Edge / 其他 Chromium 内核浏览器均可使用

---

## ✨ 功能特点

| 功能 | 说明 |
|------|------|
| **关键词扫描** | 在推文详情页加载评论，按**评论正文** / **显示名**匹配自定义关键词，含 emoji 名称容错 |
| **命中预览** | 右侧面板列出所有命中账号，每条展示**评论原文**和**命中的关键词**，方便核对 |
| **一键拉黑** | 默认全选，可手动取消勾选误伤账号；批量模拟点击 `⋯ → Block → 自动确认` |
| **词语管理** | 可视化增删关键词，内置信噪/辱骂/广告/引战四类词库，支持一键重置为默认 |
| **复制名单** | 一键复制待拉黑账号名单，便于在其它工具中继续使用 |

## 📥 安装（源码 / 开发模式加载）

> 本工具暂未上架 Chrome 网上应用店，目前通过「加载已解压的扩展程序」方式安装，整个过程约 1 分钟。Windows、macOS 操作相同。

### 第 1 步：下载代码

```bash
git clone https://github.com/onboxdeer/x-block-extension.git
# 或者：点击页面右上角绿色 Code 按钮 → Download ZIP → 解压
```

> 得到的是一个名为 `x-block-extension`（或 ZIP 解压后）的文件夹，里面包含 `manifest.json`。

### 第 2 步：打开扩展管理页

- **Chrome**：浏览器地址栏输入 `chrome://extensions/` 回车
- **Edge**：输入 `edge://extensions/` 回车

### 第 3 步：开启开发者模式

- 打开右上角的 **「开发者模式」** 开关（会弹出提示，点是）

### 第 4 步：加载扩展

1. 点击左上角 **「加载已解压的扩展程序」**
2. 选择上面下载的 **`x-block-extension` 文件夹**（注意：选到含 `manifest.json` 的那一层）
3. 加载成功后扩展会出现在列表里

### ✅ 完成

打开任意推文详情页（地址形如 `x.com/用户名/status/一串数字`），页面**右侧**会出现蓝色 **「批量拉黑」** 按钮，点击即可使用。

## 🚀 使用流程

1. 打开一篇**推文详情页**（`x.com/.../status/...`），点击右侧蓝色 **「批量拉黑」** 打开面板
2. （可选）调整词表：在面板中输入关键词 → 选类别 → 添加；点击 × 可删除；可一键重置
3. 点击 **「扫描评论和昵称」**，工具会自动展开折叠的回复并扫描评论与昵称
4. 在 **「命中账号」** 列表中核对候选，**取消勾选**不想拉黑的账号（避免误伤）
5. 点击 **「一键拉黑选中」**，批量拉黑命中账号；滚动到顶部开始，完成后弹出完成提示
6. 拉黑结束会显示完成通知，1.5 秒后自动消失

> 💡 小提示：工具拉黑时会自动滚动页面定位账号并模拟点击，过程中**请勿手动滚动或操作页面**，耐心等待完成即可。

## ⚙️ 更新与常见问题

### 我改了代码 / 想升级到新版本？

- 修改或替换 `content.js` 后，回到 `chrome://extensions/` 点击该扩展的 **「重新加载」** 按钮即可生效，无需重装
- 更换为新版本时：`chrome://extensions/` → 移除旧版 → 重新「加载已解压的扩展程序」选择新文件夹

### 我的词语表会丢吗？

不会。词表和已拉黑记录保存在浏览器 `localStorage`（键名 `xbk_words_v1` / `xbk_blocked_v1`），卸载扩展**不一定**清除，重装后通常仍在；清除浏览器站点数据才会一并清空。

### 匹配会误伤吗？

默认**全选**命中账号，拉黑前请在列表中逐条核对，取消勾选不想拉黑的账号。

### 会修改我的 X 数据吗？

不会。仅调用 X 的屏蔽操作（与你手动点 Block 完全等价），不改动任何帖子内容。

## 🔒 隐私与合规说明

- **不联网**：工具只与你当前浏览器里打开的 X 页面交互，不开任何外部连接、不上传任何数据
- **本地存储**：所有词表和记录仅保存在本机浏览器 `localStorage`
- **合规提示**：批量自动化操作用于内容治理，请合理适度使用，遵守 X 服务条款与目标地区法规
